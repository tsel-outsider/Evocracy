# Проверочные материалы RU

Этот каталог содержит сценарии проверки соответствия нормативным документам Эвократии и результаты их выполнения.

Проверочные материалы не являются самостоятельным нормативным слоем и не входят в неизменяемое Core. Расположение в canon/ru не придаёт им нормативной силы.

Сценарии не вводят полномочий, исключений, порогов, сроков или санкций. Ожидаемые результаты должны следовать из явно указанных версий нормативных документов.

Сценарии и результаты версионируются. Описание сценария, проверка формальной модели и проверка реализации фиксируются раздельно.
